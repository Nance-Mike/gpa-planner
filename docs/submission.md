## 二、作品简介（约 200 字，可直接粘贴到投稿表单）

多数绩点工具只回答「我已经考成什么样」。绩点推演器反过来问：要达到目标，剩下的课要考多少分。

录入学分与成绩，设定目标绩点与剩余学分，页面即时给出剩余课程需要达到的平均水平，并判断它落在「可以达成 / 需要冲刺 / 超出可达范围」哪一档。如果目标本身不现实，会直接算出满绩上限，避免把力气花在不可能的目标上；拖动情景滑块，还能预演不同发挥下的最终结果。

支持 4.0 制、5.0 制、百分制三种口径，覆盖多数高校的换算规则。所有数据只保存在本机浏览器，不上传、不需要登录。

## 三、使用说明（投稿表单如要求填写）

1. 先选与教务系统一致的**绩点制式**（4.0 制 / 5.0 制 / 百分制）。
2. 在「已修课程」逐门录入学分与成绩；课程多可点「批量粘贴」，一行一门，格式 `课程名 学分 成绩`。
3. 填写**目标绩点**与**剩余学分**，页面立刻给出反推结果与可行性判断。
4. 拖动「情景模拟」滑块，查看不同发挥下的最终绩点。
5. 点「生成分享卡」保存一张结果图，手机上长按即可存到相册。
