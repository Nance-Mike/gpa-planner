使用说明与算法规则

怎么用

  1. 先选绩点制式，与学校教务系统一致即可（4.0 制 / 5.0 制 / 百分制）。
  2. 选统计口径：全部课程，或只看必修课（部分学校保研只认必修）。
  3. 在「已修课程」里逐门录入学分与成绩，并选择课程类型；也可点「批量粘贴」，一行一门，格式为 课程名 学分 成绩 [类型]。
  4. 在上方填写目标绩点与剩余学分，页面即刻算出剩余课程需要达到的平均水平。
  5. 拖动情景模拟滑块，可以看不同发挥下的最终结果。
  6. 点「生成分享卡」保存结果图；数据攒得多时，建议顺手「导出备份」。

成绩怎么填

  • 直接填分数即可，如 88、86.5。
  • 也可以填等级：优秀 / 良好 / 中等 / 及格 / 不及格，或 A、A−、B+、B、C+、C 等字母等级。
  • 等级按常见中值折算（优秀 95、良好 85、中等 75、及格 65、不及格 50），折算值在行尾以 ≈ 标注，属于估算。

课程类型

  • 必修 / 选修 / 通识：用于区分统计口径，选「仅必修」时只统计必修课。
  • 不计入绩点：如体育、军事理论等通过制课程，学分照算，但不进入绩点与平均分的分母。

计算口径

  • 加权绩点 = Σ(学分 × 单科绩点) ÷ Σ学分；加权平均分同理按百分制成绩计算。
  • 剩余所需绩点 = [目标 × (已修学分 + 剩余学分) − 当前绩点 × 已修学分] ÷ 剩余学分。
  • 若该结果超过当前制式的满分，说明即便剩余课程全部满绩也无法达成目标，页面会给出可达上限。
  • 「已修学分」按当前口径统计全部有效课程；加权只取其中计入绩点的部分。

各校换算细则略有差异，本工具采用最常见的分档口径（4.0 制）与线性口径（5.0 制：绩点 =（成绩 − 50）÷ 10）。若学校另有规定，以教务系统为准。

需要注意：4.0 制是分档换算，档位之间不连续，所以「剩余课程平均需达到 3.72」在操作层面等同于「多数课程要考进 90 分档」——页面给出的「约 X 分档」就是这个含义。5.0 制与百分制为连续换算，不存在这个跳跃。

数据与备份

  • 所有数据只存在你自己的浏览器里，不上传服务器，也不需要登录。
  • 导出备份：下载一个 JSON 文件，换设备或清理浏览器后可以恢复。
  • 导入备份：选择之前导出的 JSON，会覆盖当前数据；旧版本导出的文件也能自动兼容。
  • 导出 CSV：导出课程表，方便在 Excel 里二次整理。
  • 删除单门课程或清空列表后，提示条上有「撤销」，也可以直接按 Ctrl/Cmd + Z；在最后一门课的输入框按回车可快速新增一行。
